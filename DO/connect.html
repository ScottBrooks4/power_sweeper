    The code sign-in is not your Azure DevOps session. Microsoft shows it as Visual Studio Online on another device in the United States, and DND blocks that.

    Create a token in Azure DevOps for VCDS-VCEMD. Choose Work Items, Read & write. Adding and moving circles needs that.

    This browser keeps the token until you sign out.

    Teams

    Presence uses the Microsoft account. The Azure DevOps token cannot carry it, and this page cannot see a Microsoft sign-in that lives only in the browser. Connect Teams opens that account with the code already filled in. If this browser is already signed in to Microsoft, confirm once. After that, presence stays connected. It reads available, busy, away, out of office, and whether today is in the office or planned there. An administrator may have to allow Presence.Read.All the first time.

    This sign-in also asks to read free and busy times (Calendars.ReadBasic), so the org chart can show when someone is free. It only sees what Outlook already shows you. If Microsoft says an administrator has to approve it, ask for that, then connect again.
