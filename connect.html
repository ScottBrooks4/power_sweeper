Checking the connection…

    The code sign-in is not your Azure DevOps session. Microsoft shows it as Visual Studio Online on another device in the United States, and DND blocks that.

    Create a token in Azure DevOps for VCDS-VCEMD. Choose Work Items, Read & write. Adding and moving circles needs that.

    Team presence, in-office, and calendar events are not on this token. Microsoft Graph can provide a coarse status (available, busy, in a meeting, out of office) with Presence.Read and a basic calendar read. That is the same status teammates already see. It is not a location or activity log. Team pulse shows assignments and client-support hours from the work items until that Graph permission exists.

    This browser keeps the token until you sign out.
