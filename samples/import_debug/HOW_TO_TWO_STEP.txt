Deliverables
------------

  1) CDLS_L_VCR_step1_repair.msapp
     Profile: repair_studio_errors
     Fixes locale formulas, booleans, a11y labels, focus, tooltips.
     Does NOT apply dark mode.

  2) CDLS_L_VCR_step2_dark_mode.msapp
     Profile: dark_mode (from plain — not repaired)
     Theme palettes + Settings Light/Dark. Use to test theme only.

  3) CDLS_L_VCR_step3_repair_then_dark.msapp  ← recommended
     Profiles: repair_studio_errors → dark_mode
     Best single import for day-to-day use.

Studio workflow
---------------
  A) Quick test repair: open step1 → App Checker → save.
  B) Quick test dark:   open step2 → Settings → Theme → Dark.
  C) Production:        open step3 (or step1 save → dark_mode in Power Sweeper).

App Checker note: embedded SARIF updates only after you save in Studio.

Dark mode (current):
  - App.Formulas: gblThemeLight / gblThemeDark (static named formulas)
  - Controls: If(Coalesce(gblDarkMode,false), gblThemeDark.Token, gblThemeLight.Token)
  - NOT gblTheme.Token (caused ~2300 invalid-name errors)
